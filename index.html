Accelerazione GPU Parallela

Ogni pixel rappresenta un punto nel piano complesso c = x + iy e subisce fino a centinaia di migliaia di iterazioni dell'equazione ricorsiva zn+1 = zn² + c. L'elaborazione sfrutta migliaia di core GPU simultaneamente.

🎯

Aritmetica Estesa MyFloat256

I normali numeri float IEEE-754 a 64 bit (double) degradano a fattori di zoom prossimi a 10¹⁴ producendo pixel squadrati. Il modulo proprietario a precisione estesa permette di scendere a zoom oltre 10⁴⁵ preservando nitidezza assoluta.

🎨

Ombreggiatura Continua & Palette

Per evitare le righe di discontinuità cromatica (color banding), il rendering applica un algoritmo a potenziale continuo normalizzato calcolando valori frazionari di iterazione tramite logaritmi iterati di |z|.
